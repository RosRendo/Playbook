Scope Discipline

MVP Scope Exclusion Policy (Kill List)

Features strictly prohibited prior to product-market validation and initial paying customers.

Native Mobile App

Responsive web meets 99% of early customer needs without App Store review delays.

Microservices / Kubernetes

Introduces distributed latency and network failure modes before single-host CPU saturates.

Predictive AI Recommendations

Requires substantial user data volume to be statistically meaningful.

Multi-Tenant Custom Domains

Requires complex dynamic TLS proxy infrastructure (Caddy / Cloudflare for SaaS).

Multi-Currency Dynamic Conversion

Introduces foreign exchange reconciliation overhead before validating single-currency pricing.

Granular Team Role Matrices

Simple Owner / Member permissions suffice for initial company accounts.

4. Nginx Reverse Proxy & TLS Termination Edge Gateway
Functional Role

High-performance web server terminating SSL/TLS certificates and proxying requests to internal ports.

Vulnerability Avoided

Protects application runtimes from slow-client attacks, terminates TLS efficiently, and handles gzip/brotli compression.

Verification Command
sudo nginx -t && sudo systemctl status nginx
DevOps Command Reference

Verified Infrastructure Commands

Classified by operational blast radius to prevent destructive administrative mistakes.

Stack: Docker CLI • Container Runtime Ubuntu / Linux • Host OS & Systemd Bash • Shell Automation GitHub Actions • Automated CI/CD
READ • DOCKER
docker ps -a

Lists all running and terminated containers, uptime status, and bound ports.

Verify whether the application or database crashed.
READ • DOCKER
docker logs -f --tail 100 app_container

Streams real-time stdout and stderr output from the target container.

Investigating 500-level HTTP responses or unhandled exceptions.
WRITE • NETWORK
sudo ufw allow 80/tcp && sudo ufw allow 443/tcp

Applies firewall rules permitting inbound traffic on web ports.

Enabling public web ingress. Ensure port 22 is permitted first.
READ • NETWORK
ss -tuln | grep -E ':(80|443|3000|5432)'

Scans kernel socket table for active TCP listeners on specified ports.

Resolving 'Address already in use' conflicts.
DESTRUCTIVE • SYSTEM
docker system prune -a --volumes

Removes ALL unattached containers, networks, images, and named storage volumes.

Hazard: Will wipe unbacked persistent database disks.
READ • SYSTEM
journalctl -u nginx -n 50 --no-pager

Reads the 50 most recent systemd service logs for the Nginx daemon.

Diagnosing 502 Bad Gateway errors or TLS handshake failures.
