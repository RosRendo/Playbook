§ 5 · The Difference

Amateur vs. designed, in one glance

❌ Amateur (what AI-vibecoded apps look like)

  • New hex color per screen
  • Spinners that jump the layout
  • alert() popups for success
  • Blank white screen when no data
  • "Are you sure?" on every button
  • Border-radius chaos: 4px here, 12px there
  • Raw JSON error: TypeError: null…

✅ Designed (this playbook)

  • One token source — change once, update everywhere
  • Skeletons matching real content size
  • Spring-bounce toasts, auto-dismiss
  • Empty state: illustration + guidance + CTA
  • Slide-to-confirm on irreversible actions
  • Fixed radius scale (6/10/16/full)
  • Human sentence + "Try Again" button
